A project is a folder of shots that move between DaVinci Resolve and After Effects. Create one to begin.

How the roundtrip works
  1. Create a project.
  2. In Resolve: mark IN / OUT and run export_range.
  3. Send to After Effects.
  4. Render versions.
  5. Resolve auto-updates.

Create your first shot directly from DaVinci Resolve:

  1. Open Resolve and load a project.
  2. Mark In / Out on the timeline.
  3. Run Workspace → Scripts → Utility → export_range.

The shot will appear here automatically within a few seconds.
